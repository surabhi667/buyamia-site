# Buyamia Site

Desktop homepage redesign for Buyamia — the intelligent everything marketplace network, sourced from Indonesia.

Built from the **Homepage v4** Figma redesign (byDaryaDesign).

## Stack

- React + Vite
- Plain CSS with Buyamia design tokens
- Local assets exported from Figma

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints (default `http://localhost:5173`).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm run lint` | Lint with oxlint |
